# 第二段 · EVT / DVT / PVT 老师讲稿

老师: 今天讲硬件从0到1要过的三关：EVT、DVT、PVT。 #EVT #DVT #PVT @visual:teacher @note:三关

老师: 硬件不是画完图就直接量产，中间要过三关，每一关都是一次验证。 #三关 @visual:doc @note:一关一关过

老师: EVT是工程验证，做第一版样机，验证能不能用。 #EVT @visual:evt @note:第一版样机

老师: 样子丑没关系，功能先跑通。 #能用就行 @visual:evt @note:先跑通

老师: DVT是设计验证，用改进后的样机，验证设计靠不靠谱。 #DVT @visual:dvt @note:验证设计

老师: 要摔、要淋、要测温度、电池、兼容性。 #测试 @visual:dvt @note:摔淋测

老师: PVT是量产验证，用正式产线做一小批，验证工厂能不能稳定造出来。 #PVT @visual:pvt @note:正式产线小批量

老师: 看重良率：一百台里多少台合格。 #良率 @visual:pvt @note:良率是关键

老师: 用做饭打比方。EVT是先试做一锅，看味道对不对。 #试做 @visual:evt @note:第一锅

老师: DVT是反复试做、请人试吃、调整配方。 #试吃 @visual:dvt @note:调配方

老师: PVT是按最终菜谱，让后厨一次做一百份，确认每份都一样。 #一百份 @visual:pvt @note:每份一样

老师: 每个阶段都有里程碑和评审门，不通过，不能进下一关。 #评审门 @visual:doc @note:过门才能走

老师: 风险都在这些节点暴露：延期、成本超、质量问题。 #风险 @visual:q @note:节点看风险

老师: 面试被问硬件从0到1怎么走，答这三个词就赢了。 #面试 @visual:interview @note:三个词

老师: 记住一句话：EVT验证能不能用，DVT验证靠不靠谱，PVT验证能不能稳定造出来。 #一句话记住 @visual:star @note:能用靠谱稳定

老师: 课后想一想：为什么不能画完图纸就直接生产一万台？ #课后想一想 @visual:q @note:想想三关

# B 端硬件知识库 HTML 文档站

`docs/site/` 是从项目现有 Markdown 文稿生成的离线 HTML 文档站。它参考了开发文档常见的结构：左侧分组导航、页面内目录、标题搜索、主题切换、上一篇/下一篇和源文件回链。

## 生成

在项目根目录运行：

```bash
python3 docs/build.py
```

生成内容位于 `docs/site/`。构建脚本只读取根目录知识库、`video/` 课程文稿和 `podcast/episodes/` 双人稿，不会覆盖这些原始资料。

## 本地预览

```bash
python3 -m http.server 8765 --directory docs/site
```

然后打开 <http://127.0.0.1:8765/>。如果只想快速查看，也可以直接双击 `docs/site/index.html`；搜索和主题切换在 `file://` 下仍可使用，复制代码在部分浏览器中需要通过 HTTP 服务打开。

## 内容边界

- 五份核心资料：学习路线、问题集、工业网关商业论证、量产质量与变更闭环、龙杰智能卡面试素材。
- 视频与播客的 README、索引、逐字稿和来源笔记会作为独立文档进入导航。
- 音频、视频和思维导图仍使用原项目资源；首页提供媒体入口和思维导图预览。
- 原始 Markdown 是唯一事实来源，HTML 是可重复生成的阅读层。

**一句话定义**

客户价值地图 = 把客户完成某件事的完整过程画出来，标出他们每一步在做什么、哪里痛、想要什么结果，以及你的产品或方案能在哪些环节创造价值。

它回答三个问题：

1. 客户现在是怎么做的？
2. 哪里让他不爽或付出成本？
3. 我们能在哪里替他消除、简化或提升？

**两种常见理解**

- 广义：梳理客户行为链的工具，从触发需求到最终完成，逐段记录动作、痛点、期望结果和价值切入点。
- 狭义：价值主张画布（Value Proposition Canvas）的左半部分 Value Map，包含产品与服务、Pain Relievers（痛点消除）、Gain Creators（收益创造），并与右侧客户画像匹配。

**地图四层结构**

| 层 | 内容 |
| --- | --- |
| 当前行为 | 客户从发现问题到解决，具体做了哪些步骤，用了什么工具 |
| 痛点 | 浪费时间、额外成本、出错风险、体力劳动、协调麻烦 |
| 期望结果 | 客户希望达到的效率、成本、稳定性，以及情感和社会层面收益 |
| 价值机会 | 产品能替代、简化、加速、降低风险或带来新能力的环节 |

**怎么画一张客户价值地图**

1. 选一个具体场景，不要泛泛画整个客户。
2. 从触发点开始：什么事件让客户发现问题？
3. 按时间线列步骤：调研、比较、试用、购买、部署、使用、维护、汇报。
4. 每一步记录：客户做了什么、花了多少时间和成本、痛在哪里、期望变成什么。
5. 最后标出机会点：哪几步可以被自动化、替代或简化，哪里的痛最强烈且最愿意付费。

**工业网关示例**

- 当前行为：巡检员每天到现场抄表，回办公室录 Excel，主管每周汇总，发现异常再派人处理。
- 痛点：漏抄、数据滞后、人工成本高、故障发现晚导致停产、Excel 易错。
- 期望结果：实时看到设备状态，异常自动报警，减少巡检人力，数据进系统。
- 价值机会：用网关自动采集替代人工抄录，用平台告警替代事后发现。

**和 JTBD 的关系**

- JTBD 回答：客户雇佣产品完成什么任务。
- 客户价值地图回答：任务发生在哪些环节、痛点在哪里、收益在哪里。
- 用户旅程图回答：客户体验在时间上的路径。
- PRD 回答：用哪些具体功能实现价值点。

顺序通常是：先有 JTBD，再用客户价值地图找到价值和痛点，最后落到产品规格。

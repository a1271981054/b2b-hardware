**一句话定位**

B 端硬件产品经理的职责 = 在正确的市场机会里定义对的产品，推动它在成本、质量、时间和商业回报上成立，并持续经营到生命周期结束。

**职责三层模型**

1. 商业层（Why）：市场和客户洞察、目标行业、商业模式、定价、商业论证（business case），对收入和毛利负责。
2. 产品层（What）：需求优先级、产品定义、产品规格书，明确功能、性能、接口、环境、可靠性和成本目标。
3. 交付层（How）：牵头硬件、结构、固件、测试、认证、供应链、生产和售后协同，做阶段评审、变更决策和风险管理。

成熟公司会把交付层进一步拆出 NPI PM 或项目 PM，但硬件产品经理仍然对产品最终结果负责。

**职责 vs 协作**

| 产品经理该负责 | 产品经理该协调、不亲自做 |
| --- | --- |
| 需求定义 | 电路、结构、固件设计 |
| 商业论证和定价 | 采购与供应商谈判 |
| 阶段评审与放行建议 | 认证测试执行 |
| 变更决策 | 生产制造和工艺 |
| 上市准备输入 | 销售签单和渠道管理 |

**KPI 方法论：商业结果 + 阶段门双轨**

北极星指标优先选「健康毛利下的持续收入或客户数」，例如目标毛利率达成后持续付费的活跃客户数。阶段门 KPI 按生命周期切换，不要一套指标打到底。

| 阶段 | 核心 KPI |
| --- | --- |
| 立项 | 目标价格、目标毛利、市场规模、NPV 或 ROI、预测销量 |
| 开发 | 计划交期、BOM 成本偏差、需求变更次数、工程问题关闭率 |
| 试产与量产 | 直通率、良率、认证通过、单位成本、供应链交期 |
| 上市 | 订单与收入、毛利率、首批客户数、渠道覆盖率 |
| 售后 | 现场故障率、年返修率、RMA、NPS 或 CSAT、续购率 |

落地建议：KPI 控制在 3 到 6 个，每个阶段只突出 1 到 2 个北极星指标和 2 到 3 个护栏指标；职责边界模糊时，先判断问题属于定义问题、执行问题还是资源问题。

**示例：一款工业网关**

- 北极星：目标毛利下，年活跃客户数。
- 立项 KPI：目标售价 1200 元、目标毛利 45%、首年预测 500 台。
- 开发 KPI：BOM 成本不高于 660 元、立项后 10 个月内完成量产。
- 量产 KPI：直通率不低于 95%、现场年故障率不高于 2%。
- 售后 KPI：续购率不低于 60%。

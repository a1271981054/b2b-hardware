**总方法：五个商业问题**

1. 为谁解决什么真问题？（市场与客户洞察）
2. 先进入哪些行业？（目标行业选择）
3. 用什么方式赚钱？（商业模式）
4. 收多少钱、怎么收？（定价）
5. 值不值得投入？（商业论证）

**1. 市场与客户洞察**

框架：JTBD + 客户价值地图 + 决策链分析。

- JTBD：客户雇佣这个产品完成什么任务？成功的标准是什么？
- 客户价值地图：客户现在怎么做、痛在哪里、期望达到什么结果。
- 决策链分析：谁是使用者、影响者、预算者、决策者、采购者。

筛选公式：机会分 = 痛点强度 × 发生频率 × 支付意愿 × 可触达性。每个维度按 1 到 5 分打分，低于阈值的细分市场先不做。

**2. 目标行业选择**

框架：行业吸引力 × 可进入性矩阵。

- 行业吸引力：市场规模、增速、付费意愿、监管利好、竞争强度。
- 可进入性：技术能力、行业 Know-how、认证资质、渠道、服务网络、标杆客户。
- 每个行业打分后进入四象限：优先打「高吸引力 + 高可进入性」，其次补「高吸引力 + 中可进入性」的能力缺口。

**3. 商业模式**

框架：商业模式画布 + 收入结构设计。

- 价值主张：帮客户省钱、赚钱、避险还是省人。
- 收入模式：硬件一次性、硬件 + 订阅、服务费、项目制、HaaS。
- 渠道结构：直销、经销商、集成商、OEM。
- 判断标准：客户预算形态（CAPEX 还是 OPEX）、回款周期、竞争壁垒、公司现金流。

**4. 定价**

框架：3C 定价 + EVC/TCO + 价格阶梯 + 价格瀑布。

- 成本：决定价格下限。
- 客户：EVC = 客户当前方案 TCO - 新方案 TCO，决定价值定价上限。
- 竞争：决定参考价格区间。
- 最终定价区间 = 成本下限到 EVC 上限，再根据竞争位置落在区间内。
- 价格瀑布：目录价 → 渠道折扣 → 项目折扣 → 返利 → 实际净收入。

**5. 商业论证**

框架：5 年 P&L + 单位经济 + NPV/IRR/回收期 + 情景分析 + Stage-Gate。

- 单位经济：毛利 =（售价 - 变动成本 - 售后预留）× 销量 - 固定投入。
- 投入盘点：NRE、模具、认证、首批库存、市场费用。
- 情景分析：保守、基准、乐观三套预测。
- 阶段门：每个阶段重新验证商业目标是否仍然成立，再决定 Go / No-Go。

**一页纸商业论证模板**

| 模块 | 要回答的问题 |
| --- | --- |
| 客户与痛点 | 目标客户是谁？JTBD 和痛点强度？ |
| 市场规模 | TAM / SAM / SOM 分别多大？ |
| 行业选择 | 吸引力分和可进入性分是多少？ |
| 竞争定位 | 客户现在用什么？我们的差异化是什么？ |
| 商业模式 | 收入结构、渠道、客户预算形态？ |
| 定价 | 目录价、价格区间、价格底线？ |
| 销量预测 | 保守、基准、乐观各多少台？ |
| 财务 | 5 年收入、毛利、投入、NPV、回收期？ |
| 风险 | 前三风险是什么？怎么对冲？ |
| 决策 | Go / No-Go / 再调研？ |

**一句话理解**

商业模式 = 客户为什么买 + 我们怎么赚钱 + 我们凭什么一直赚。

**商业模式画布九格（简化）**

| 模块 | 要回答的问题 |
| --- | --- |
| 客户细分 | 卖给谁 |
| 价值主张 | 凭什么买 |
| 渠道 | 怎么触达 |
| 客户关系 | 怎么长期保持 |
| 收入来源 | 从哪收钱 |
| 关键资源 | 靠什么做出来 |
| 关键活动 | 每天做什么 |
| 关键伙伴 | 靠谁一起做 |
| 成本结构 | 钱花在哪 |

**价值主张四类**

- 省钱：帮客户降低采购、人工、运维、能耗成本。
- 赚钱：帮客户增加收入，例如提升产能、提高利用率。
- 避险：帮客户减少安全、合规、质量、停产风险。
- 省人：帮客户减少人力投入或降低对人的依赖。

判断标准：客户是否愿意付钱，取决于价值是否可量化、可感知、紧迫。

**四种收入模式对比**

| 模式 | 专业解释 | 通俗解释 | 优点 | 风险 |
| --- | --- | --- | --- | --- |
| 硬件一次性销售 | 销售设备所有权，收一次钱 | 卖硬件 | 现金流快、简单 | 毛利压力、无续购、比价 |
| 硬件 + 软件订阅 | 硬件引流，软件按周期收费 | 低价卖盒子，按月收平台费 | 持续收入、锁定客户 | 软件要持续有价值 |
| 服务费或项目制 | 按项目交付和定制收费 | 按项目收钱 | 毛利高、贴合需求 | 难规模化、交付重 |
| HaaS | 客户按月付费使用设备 | 设备不收钱，按月租 | 门槛低、持续收入 | 占用公司资金、回本慢 |

**四个判断标准**

1. CAPEX vs OPEX：客户是一次性采购预算，还是按月运营支出？
2. 回款周期：多久能收到钱？一次性最快，项目制最慢。
3. 竞争壁垒：硬件本身壁垒低，软件、数据、服务壁垒高。
4. 公司现金流：钱紧就做一次性加预付款，钱多才做订阅或 HaaS。

**为什么健康结构是「硬件打基础 + 软件/服务做利润」**

硬件解决获客和触达，软件或服务解决持续收入和锁定。硬件可以微利甚至平价，利润放在订阅、平台、服务里。

**工业网关示例**

- 一次性：卖 1200 元/台，毛利 45%，收入一次结清。
- 硬件 + 订阅：卖 800 元/台 + 50 元/月/台，首年 1400 元，第二年起每年 600 元。
- 项目制：100 台设备 + 部署 + 一年运维，收 30 万。
- HaaS：99 元/月/台，签 5 年，客户门槛低，但公司垫资重。

**选择口诀**

客户怎么买 + 自己有没有钱 + 能不能持续创造价值，三个条件决定模式。

**常见错误**

- 所有模式都做，没有重点。
- 硬件免费，却没有软件或服务赚钱。
- 客户只有一次性预算，硬推订阅。
- 把项目制当产品做，交付完就散。
- 没有服务能力硬上 HaaS。

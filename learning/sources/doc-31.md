- 中间要过三关，每一关都是一次验证
- 英文缩写：EVT、DVT、PVT


- 全称 Engineering Validation Test
- 第一版样机，验证「能不能用」
- 样子丑没关系，功能先跑通


- 全称 Design Validation Test
- 改进后的样机，验证「设计靠不靠谱」
- 要摔、要淋、要测温度、电池、兼容性


- 全称 Production Validation Test
- 用正式产线做一小批，验证「工厂能不能稳定造出来」
- 看重良率：100 台里多少台合格


- EVT = 先试做一锅，看味道对不对
- DVT = 反复试做、请人试吃，调整配方
- PVT = 按最终菜谱让后厨一次做 100 份，确认每份都一样


- 每个阶段都有里程碑和评审门，不通过不能进下一关
- 风险都在这些节点暴露：延期、成本超、质量问题
- 面试被问「硬件从 0 到 1 怎么走」，答这三个词就赢了


EVT 验证能不能用，DVT 验证靠不靠谱，PVT 验证能不能稳定造出来。

# 第二段 · 开模、NRE、MOQ 老师讲稿

老师: 今天讲三个跟钱有关的词：开模、NRE、MOQ。 #开模 #NRE #MOQ @visual:teacher @note:三个花钱的词

老师: 先说开模。塑料外壳不是打印出来的，是用模具压出来的。 #模具 @visual:mold @note:模具压外壳

老师: 模具像做月饼的模子：先花大钱做模子，之后每个外壳都用同一个模子做。 #月饼模子 @visual:mold @note:先做模子再生产

老师: 做一个模具可能要几十万，这是一次性投入。 #贵 @visual:mold @note:几十万一次

老师: NRE全称Non-Recurring Engineering，就是只花一次的钱：设计费、开模费、认证费。 #NRE @visual:nre @note:只花一次的钱

老师: 不做产品就没有这笔钱，做多少台都要先付这一笔。 #先付钱 @visual:nre @note:开工先花

老师: MOQ全称Minimum Order Quantity，就是最小起订量。 #MOQ @visual:moq @note:最小订单量

老师: 工厂不愿意只做几台，因为开一次产线很贵，常见要求一次至少一千台、五千台。 #起订量 @visual:moq @note:最少1000台

老师: 量太小，工厂连成本都收不回来。 #成本 @visual:moq @note:量小亏本

老师: 为什么PM必须懂？因为总成本等于NRE一次性，加上BOM每台乘数量。 #总成本 @visual:money @note:NRE加BOM乘数量

老师: 量小的时候，NRE摊到每台特别贵。所以硬件要走量，量越大，每台摊的固定成本越低。 #走量 @visual:chart @note:量越大越便宜

老师: 记住一句话：开模和NRE是一次性的钱，BOM是每台的钱，MOQ是工厂的最小订单。 #一句话记住 @visual:star @note:三种钱分清

老师: 课后想一想：为什么工厂要求一次最少做一千台，不能一台一台做？ #课后想一想 @visual:q @note:一句就行

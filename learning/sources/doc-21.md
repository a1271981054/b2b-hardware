# 第二段 · BRD / MRD / PRD 老师讲稿

老师: 今天讲产品经理天天要写的三份文档：BRD、MRD、PRD。 #BRD #MRD #PRD @visual:teacher @note:三份文档

老师: 产品经理的很多活，最后都落在写文档上。 #写文档 @visual:doc @note:活都在文档里

老师: BRD是商业需求文档，给老板看的，回答为什么做。 #BRD @visual:brd @note:为什么做

老师: 市场机会值不值得、投入多少、能赚多少，都是BRD回答的。 #商业价值 @visual:brd @note:值不值得

老师: MRD是市场需求文档，给市场和产品团队看的，回答做给谁。 #MRD @visual:mrd @note:做给谁

老师: 目标客户、市场多大、竞品怎样、客户痛点，都是MRD回答的。 #目标客户 @visual:mrd @note:客户痛点

老师: PRD是产品需求文档，给研发、设计、测试看的，回答做什么、做到什么标准。 #PRD @visual:prd @note:做什么做到多好

老师: 功能、规格、验收标准，都是PRD回答的。 #验收标准 @visual:prd @note:验收标准

老师: 用盖房子打比方。BRD是跟投资人讲，这块地值不值得盖、能赚多少。 #盖房子 @visual:brd @note:先讲值不值

老师: MRD是讲这房子卖给谁、他们需要什么。 #卖房 @visual:mrd @note:卖给谁

老师: PRD是施工图纸：墙多厚、门多宽、用什么砖。 #施工图 @visual:prd @note:施工图纸

老师: 顺序是BRD到MRD到PRD，从为什么，到做给谁，到做什么。 #顺序 @visual:doc @note:为什么到做什么

老师: 记住一句话：BRD回答为什么做，MRD回答做给谁，PRD回答做什么、做多好。 #一句话记住 @visual:star @note:三个问题

老师: 课后想一想：老板问你，这个产品值不值得做，这是哪个文档要回答的问题？ #课后想一想 @visual:q @note:答案是BRD

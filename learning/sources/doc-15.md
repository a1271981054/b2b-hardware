# 第一段 · 龙杰（ACS）怎么赚钱 老师讲稿

老师: 今天看看龙杰这家公司怎么赚钱，像看一个小老板，靠四条路子赚钱。 #赚钱 @visual:money @note:四条赚钱路子

老师: 第一条，卖标准产品：读卡器、卡片，卖给全球一百多个国家的分销商。 #标准产品 @visual:pos @note:走量卖全球

老师: 第二条，卖定制产品：客户印自己的牌子，改外观、改功能，ACS收定制费。 #定制产品 @visual:doc @note:贴牌收钱

老师: 第三条，卖零件：读卡器模块，卖给别的公司，装进他们的机器。 #模块 @visual:module @note:卖零件

老师: 第四条，卖服务和方案：SDK、技术支持、公交收费整套方案、卡打印、咨询。 #服务方案 @visual:gate @note:卖方案和服务

老师: 看几个真实数字。2025财年，收入九千一百五十万港元，同比降了百分之九。 #收入 @visual:chart @note:收入降9%

老师: 毛利率百分之五十九，很高，说明产品本身很赚钱。 #毛利率 @visual:chart @note:毛利59%

老师: 净亏损五百一十万港元，就是花钱比赚钱多了一点点。 #净亏损 @visual:chart @note:亏一点点

老师: 亚太区收入增长百分之四十八点七，欧洲下滑百分之三十五。 #增长 @visual:chart @note:亚太是引擎

老师: 这些数字告诉我们：卖一台赚一台，毛利很高，但公司规模不大。 #毛利高 @visual:chart @note:单台赚得多

老师: 亚太是增长引擎，中国市场很关键。 #亚太 @visual:chart @note:增长看亚太

老师: 产品经理要帮公司想：怎么在亚太多卖，怎么让定制项目更赚钱。 #产品经理 @visual:light @note:帮公司想增长

老师: 记住一句话：ACS靠标准品走量、定制项目拿单、认证护城河赚钱，不是靠月租订阅。 #一句话记住 @visual:star @note:走量加单加护城河

老师: 课后想一想：ACS除了卖读卡器，还能从哪些地方赚钱？ #课后想一想 @visual:q @note:说一个就行

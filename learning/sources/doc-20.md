# 第二段 · OEM 和 ODM 老师讲稿

老师: 今天讲两个字母组合，OEM和ODM，回答一个问题：自己造，还是找人造。 #OEM #ODM @visual:teacher @note:自己造还是找人

老师: 这是产品经理立项时就要回答的问题。 #立项 @visual:doc @note:立项先回答

老师: OEM叫贴牌代工：客户出设计，工厂按图纸生产。 #OEM @visual:oem @note:你设计工厂做

老师: 产品是你的设计，牌子也是你的。你管做什么，工厂管怎么造出来。 #贴牌 @visual:oem @note:你管做什么

老师: 就像你写好菜谱，交给后厨做。 #菜谱 @visual:oem @note:后厨照做

老师: ODM叫设计代工：工厂自己有现成设计，你选一款，改改外观和软件。 #ODM @visual:odm @note:选现成的改改

老师: 工厂管设计加生产，你主要管卖。 #省事 @visual:odm @note:你管卖

老师: 像后厨已有招牌菜，你改个摆盘，端出去卖。 #招牌菜 @visual:odm @note:改摆盘就卖

老师: 怎么选？自研投入大、周期长，但控制力强，别人难抄。 #自研 @visual:doc @note:贵但可控

老师: OEM是有设计但不想建厂，省生产投入。 #OEM选择 @visual:oem @note:省建厂

老师: ODM最快最省钱，但产品容易跟别人一样。 #ODM选择 @visual:odm @note:快但容易一样

老师: 和ACS的关系：ACS的定制产品生意，就是OEM和ODM，客户印自己的牌子，ACS帮他做。 #ACS @visual:module @note:ACS也做这个

老师: 记住一句话：OEM是你设计、工厂做；ODM是工厂设计好，你挑一款改改就卖。 #一句话记住 @visual:star @note:谁设计谁说了算

老师: 课后想一想：想最快、最省钱推出一款读卡器，选OEM还是ODM？为什么？ #课后想一想 @visual:q @note:选哪个

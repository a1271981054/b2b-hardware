# 第一段 · 读卡器用在哪些地方 老师讲稿

老师: 今天像逛街一样，看看读卡器都用在哪里。 #应用场景 @visual:teacher @note:像逛街看场景

老师: 第一个场景，POS机，就是超市餐厅收银台，刷卡或贴卡付钱。 #POS机 @visual:pos @note:收银台付钱

老师: 这里的要求：安全、稳定，不能付到一半死机。 #要求 @visual:pos @note:安全稳定快

老师: 第二个场景，公交、地铁、停车，叫AFC自动售检票。 #AFC @visual:gate @note:闸机滴一下

老师: 这里的要求：读卡要快，高峰期不能让人排队。 #要求 @visual:gate @note:快，不能排队

老师: 第三个场景，门禁和考勤，刷卡进门，打卡上班。 #门禁考勤 @visual:access @note:进门打卡

老师: 这里的要求：耐用、好管理。 #要求 @visual:access @note:结实好用

老师: 第四个场景，身份证件读取，银行柜面、酒店、政府窗口。 #身份证件 @visual:id @note:读身份证护照

老师: 这里的要求：准、稳、安全。 #要求 @visual:id @note:不能读错

老师: 第五个场景最特别：ACS把读卡器零件卖给别的公司，人家装进自己的机器。 #模块 @visual:module @note:卖发动机给汽车厂

老师: 为什么产品经理要懂场景？因为同一个读卡器，场景不同，要求完全不同。 #场景思维 @visual:light @note:先问在哪用谁用

老师: 公交要快，POS要安全，户外要防水。先问在哪用、谁用、怎么用，再定规格。 #先问再用 @visual:doc @note:场景决定规格

老师: 记住一句话：先问在哪用，再定规格。 #一句话记住 @visual:star @note:场景决定一切

老师: 课后想一想：你生活里见过哪些滴一下或插一下卡的地方？ #课后想一想 @visual:q @note:举一个例子

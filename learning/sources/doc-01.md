# 课堂笔记：从零学 B 端硬件产品经理

> 这是一份主学习文档。目标不是把我教成研发工程师，而是让我能通过龙杰智能卡的 B 端硬件产品经理面试，并能在真实工作中听懂客户、销售、研发、供应链和认证团队的话。
>
> 学习方式：口语化、慢慢拆、一次只讲一个完整主题。每次课程由“老师讲清楚 → 我做一个小练习 → 老师纠正 → 我说下一步”组成。不用一次背很多英文缩写，也不在没有必要时钻进研发实现细节。
>
> 当前进度：智能卡、读卡器、NFC、EMV、认证、硬件开发阶段、龙杰公司和面试基础已经学过；现在进入 B 端硬件产品经理的主线实战课，当前主题是“市场调研”。

## 主学习路线

这套路线只围绕一个问题展开：产品经理怎样发现一个值得做的产品，并把它从想法推进到上市和赚钱。

1. 认识公司和产品：看懂龙杰卖什么、卖给谁、靠什么赚钱，以及标准品、定制品、读卡器模块和整套方案的区别。
2. 市场调研：判断哪个行业、哪个地区、哪类客户值得进入，不把“搜资料”误当成“做调研”。
3. 客户需求：学会找使用者、购买者、技术决策者和最终拍板人，问出真实场景、真实痛点和 JTBD。
4. 竞品和商业判断：比较客户现有方案、竞争对手和自研方案，算清价格、成本、利润、销量和风险。
5. 立项和产品定义：把调研结论变成 BRD、产品目标、需求优先级、规格和验收标准。
6. 可行性和开发推进：从市场、技术、供应链、认证、成本和交付几个方面做评审，再推动 EVT、DVT、PVT 和量产。
7. 上市和产品经营：做定价、渠道、销售工具、试点、上市、售后和产品迭代，知道标准品和定制项目怎样平衡。
8. 面试实战：把前面的做法讲成清楚、可信、有步骤的面试回答，并用龙杰的产品场景反复练习。

## 每一课怎么进行

我不会一口气讲完一大堆。每次只解决一个问题，比如“市场调研第一步到底做什么”。我先用生活中的话讲明白，再用龙杰的读卡器或模块举例，最后让你做一个很小的练习。你回答后，我会告诉你哪里对、哪里要改；你说“下一步”，我们才进入下一课。

如果某个词听不懂，你直接说“换个说法”；如果内容太快，你直接说“慢一点”；如果你想先练面试，就说“按面试教我”。学习速度由你控制，但主线不会乱。

## 当前课程位置：市场调研

本课要掌握的不是“市场规模有多大”这种空话，而是下面这个动作：

> 先把调研目标写成一个要做的决定，再去找客户、找资料、看竞品，最后给出“做、暂缓还是不做”的建议。

当前练习场景是：假设龙杰想研究，是否应该面向亚太地区的自助终端厂商推广读卡器模块。下一步课堂会继续讲如何找调研对象、如何设计客户访谈问题，以及怎样判断客户的需求是真的还是假的。

## 已经学过的基础知识

## 第 1 课：这一行到底在卖什么

### 智能卡

- 一张塑料卡片，里面藏着一小块芯片，像一台微型小电脑
- 能存信息、能算数、能核对身份
- 例子：饭卡、公交卡、银行卡
- 老式磁条卡像一张写了字的纸，只会存信息
- 智能卡像一个小保安，会核对密码再说放不放行

### 读卡器

- 专门跟卡片对话的设备
- 比喻：卡片是钥匙，读卡器是门卫
- 龙杰智能卡（ACS）就是造卡片和读卡器的公司

### 两种读卡方式

- 接触式：卡片要插进去，芯片碰到读卡器，像插 U 盘
- 非接触式：卡片靠近就行，像地铁闸机滴一下

### NFC

- 两个东西靠得很近（几厘米）就能互相说话的技术
- 手机付钱滴一下，就是 NFC

### 一句话记住

ACS 卖的不是手机，是「刷卡基础件」：卡片、读卡器、还有装进别人机器里的读卡器零件。

## 第 2 课：什么是 NFC、什么是 EMV

### NFC（近场通信）

- 两个东西靠得很近（几厘米）就能互相说话
- 像两个人贴着耳朵说悄悄话，别人听不见
- 手机付钱「滴」一下，就是 NFC 在对话
- 为什么必须靠得近：离太远，别人可能从远处偷走你的支付信息

### EMV

- 三个大公司定的全世界刷卡共同规矩：Europay、Mastercard、Visa
- EMV = 银行卡行业的「共同普通话」+ 安全规则
- 老式磁条卡容易造假；EMV 芯片卡会算密码、会加密，很难克隆
- 为什么产品经理要懂：读卡器不通过 EMV 认证，银行和支付机构就不收，产品卖不出去

### 一句话记住

NFC 是「两个设备怎么说话」，EMV 是「刷卡必须遵守的共同规矩和安全考试」。

## 第 3 课：为什么硬件要做认证

### 认证是什么

- 认证 = 让一个独立的、有公信力的机构来考你的产品
- 考过了，就发一张「合格证」；考不过，就不能卖
- 像人开车要考驾照，食品要拿合格证，产品也要拿「上岗证」

### 认证为什么重要（三个原因）

1. 安全：证明产品不会起火、不会伤人、不会辐射超标（如 3C、CE、FCC）
2. 互通：证明产品能跟别家的卡、别家的机器配合（如 EMV、NFC Forum）
3. 市场准入：没有认证，银行不收、国家不让卖、客户不敢买

### 为什么产品经理必须懂

- 认证要花几个月时间和不少钱，必须排进项目计划
- 认证没排进去，产品做完了也上不了市，项目就砸了
- 认证是硬件公司的护城河：ACS 产品带 EMV、NFC Forum、Apple MFi 等一堆认证，这就是它难被替代的地方

### 一句话记住

硬件产品不是「做出来就能卖」，是「考过试才能卖」。

## 第 4 课：读卡器用在哪些地方

### 场景 1：POS 机 / 收银机

- 超市、餐厅收银台，刷卡或贴卡付钱
- 要求：安全（EMV）、稳定（不能付到一半死机）、快

### 场景 2：公交、地铁、停车（AFC 自动售检票）

- 闸机「滴」一下，扣费放行
- 要求：读卡要快，高峰期不能让人排队

### 场景 3：门禁、考勤

- 刷卡进门、打卡上班
- 要求：耐用、好管理

### 场景 4：身份证件读取

- 银行柜面、酒店、政府窗口读身份证、护照
- 要求：准、稳、安全

### 场景 5：把读卡器零件卖给别的公司（模块）

- ACS 不只卖整机，还卖「读卡器模块」
- 别的公司买回去，装进自己的机器里
- 像卖发动机给汽车厂

### 为什么产品经理要懂场景

- 同样一个读卡器，不同场景要求完全不同
- 公交要快，POS 要安全，户外要防水
- 先问「在哪用、谁用、怎么用」，再定规格

## 第 5 课：龙杰（ACS）怎么赚钱

### 四条赚钱路子

1. 卖标准产品：读卡器、卡片，卖给全球 100+ 国家的分销商
2. 卖定制产品：客户要求印自己的牌子、改外观、改功能，ACS 收定制费
3. 卖零件：读卡器模块，卖给别的公司装进他们的机器
4. 卖服务和方案：SDK、技术支持、公交收费（AFC）整套方案、卡打印、咨询

### 公司真实数字（2025 财年，公开业绩）

- 收入：9,150 万港元（同比降 9%）
- 毛利率：59%（很高，说明产品本身赚钱）
- 净亏损：510 万港元（花钱比赚钱多了一点）
- 亚太区收入增长 48.7%，欧洲下滑 35%

### 数字告诉我们什么

- 卖一台赚一台的毛利很高，但公司规模不大
- 亚太是增长引擎，中国市场很关键
- 产品经理要帮公司想：怎么在亚太多卖、怎么让定制项目更赚钱

### 一句话记住

ACS 靠「标准品走量 + 定制项目拿单 + 认证护城河」赚钱，不是靠月租订阅。

### 第 1 课：BOM 是什么

- BOM 全称 Bill of Materials，中文叫「物料清单」
- 就是一台机器里所有零件的清单：芯片、屏幕、电池、外壳、按键、螺丝、包装
- 像做饭的菜谱加购物清单：用什么材料、各用多少、各花多少钱
- 把清单上所有价格加起来，就是这台机器的材料成本
- 材料成本决定毛利：卖价 - 材料成本 - 其他费用 = 赚多少
- 产品经理的活：定成本目标、参与选型、管住变更（换个零件可能影响认证）

### 一句话记住

BOM 就是「这台机器值多少钱的材料账本」。

### 第 2 课：开模、NRE、MOQ

#### 开模（模具）

- 塑料外壳不是直接打印出来的，是用「模具」压出来的
- 模具像做月饼的模子：先花大钱做模子，之后每个外壳都用同一个模子做
- 做一个模具可能要几十万，这是一次性投入

#### NRE（一次性研发费用）

- 全称 Non-Recurring Engineering
- 就是「只花一次的钱」：设计费、开模费、认证费
- 不做产品就没有，做多少台都要先付这一笔

#### MOQ（最小起订量）

- 全称 Minimum Order Quantity
- 工厂不愿意只做几台，因为开一次产线很贵
- 常见要求：一次至少做 1000 台、5000 台
- 量太小，工厂连成本都收不回来

#### 为什么产品经理必须懂

- 总成本 = NRE（一次性）+ BOM（每台）× 数量
- 量小的时候，NRE 摊到每台特别贵
- 所以硬件产品要「走量」，量越大，每台摊的固定成本越低

#### 一句话记住

开模和 NRE 是「一次性的钱」，BOM 是「每台的钱」，MOQ 是「工厂的最小订单」。

### 第 3 课：EVT / DVT / PVT

#### 硬件不是「画完图就直接量产」

- 中间要过三关，每一关都是一次验证
- 英文缩写：EVT、DVT、PVT

#### EVT（工程验证）

- 全称 Engineering Validation Test
- 第一版样机，验证「能不能用」
- 样子丑没关系，功能先跑通

#### DVT（设计验证）

- 全称 Design Validation Test
- 改进后的样机，验证「设计靠不靠谱」
- 要摔、要淋、要测温度、电池、兼容性

#### PVT（量产验证）

- 全称 Production Validation Test
- 用正式产线做一小批，验证「工厂能不能稳定造出来」
- 看重良率：100 台里多少台合格

#### 做饭的比喻

- EVT = 先试做一锅，看味道对不对
- DVT = 反复试做、请人试吃，调整配方
- PVT = 按最终菜谱让后厨一次做 100 份，确认每份都一样

#### 产品经理为什么必须懂

- 每个阶段都有里程碑和评审门，不通过不能进下一关
- 风险都在这些节点暴露：延期、成本超、质量问题
- 面试被问「硬件从 0 到 1 怎么走」，答这三个词就赢了

#### 一句话记住

EVT 验证能不能用，DVT 验证靠不靠谱，PVT 验证能不能稳定造出来。

### 第 4 课：OEM 和 ODM

#### 先记住一句话

自己造还是找人造，是产品经理立项时就要回答的问题。

#### OEM（贴牌代工）

- 客户出设计，工厂按图纸生产
- 产品是你的设计，牌子也是你的
- 你管「做什么」，工厂管「怎么造出来」
- 像你写好菜谱，交给后厨做

#### ODM（设计代工）

- 工厂自己有现成设计，你选一款，改改外观和软件
- 工厂管「设计 + 生产」，你主要管「卖」
- 像后厨已有招牌菜，你改个摆盘，端出去卖

#### 怎么选

- 自研：投入大、周期长，但控制力强，别人难抄
- OEM：有设计但不想建厂，省生产投入
- ODM：最快、最省钱，但产品容易跟别人一样

#### 和 ACS 的关系

- ACS 的「定制产品」生意就是 OEM / ODM
- 客户印自己的牌子，ACS 帮他做

#### 一句话记住

OEM 是你设计、工厂做；ODM 是工厂设计好，你挑一款改改就卖。

### 第 5 课：BRD / MRD / PRD

#### 先记住一句话

产品经理的很多活，最后都落在「写文档」上。

#### BRD（商业需求文档）

- 给老板看的
- 回答「为什么做」：市场机会、值不值得、投入多少、能赚多少

#### MRD（市场需求文档）

- 给市场和产品团队看的
- 回答「做给谁」：目标客户、市场多大、竞品怎样、客户痛点

#### PRD（产品需求文档）

- 给研发、设计、测试看的
- 回答「做什么、做到什么标准」：功能、规格、验收标准

#### 盖房子的比喻

- BRD = 跟投资人讲：这块地值不值得盖、能赚多少
- MRD = 讲这房子卖给谁、他们需要什么
- PRD = 施工图纸：墙多厚、门多宽、用什么砖

#### 顺序

BRD → MRD → PRD：从「为什么」到「做给谁」到「做什么」。

#### 一句话记住

BRD 回答为什么做，MRD 回答做给谁，PRD 回答做什么、做多好。

### 第 6 课：综合模拟面试

#### 把两个段的知识串起来

- 行业知识：卡片、读卡器、NFC、EMV、认证、场景、ACS 怎么赚钱
- 硬件 PM 知识：BOM、开模、NRE、MOQ、EVT/DVT/PVT、OEM/ODM、BRD/MRD/PRD

#### 综合题：开发一款新的蓝牙 NFC 读卡器，怎么从 0 到 1 推动？

1. 先写 BRD：为什么做、市场多大、投多少、能赚多少
2. 再想客户：谁用、在哪用、痛点是什么（NFC 靠得近，蓝牙解决移动场景）
3. 写 PRD：功能、规格、认证目标（EMV / NFC Forum / 蓝牙认证）
4. 选方式：自研还是 OEM/ODM
5. 走流程：EVT → DVT → PVT，认证排进计划
6. 上市：定价、渠道、售后

#### 一句话记住

面试问「怎么做产品」，就按「为什么做 → 做给谁 → 做什么 → 怎么造 → 怎么卖」回答。

- NFC：两个东西靠得很近（几厘米）就能互相说话的技术
- EMV：全世界刷卡必须遵守的共同规矩和安全规则
- POS 机：收银台刷卡/贴卡付钱的机器
- AFC：自动售检票，公交、地铁、停车那套自动收费系统
- FIDO：一种安全登录标准，用硬件钥匙代替密码
- SAM 槽：读卡器上的安全模块插槽，用来放更高等级的加密卡
- SDK：给开发者用的工具包，让他们写程序调用你的硬件
- BOM：物料清单，一台机器所有零件的成本账本
- NRE：一次性研发费用，比如设计费、开模费、认证费
- MOQ：工厂的最小起订量，比如一次至少 1000 台
- 开模：花大钱做一个金属模具，之后每个外壳都用它压出来
- EVT：工程验证，第一版样机验证能不能用
- DVT：设计验证，改进后的样机验证设计靠不靠谱
- PVT：量产验证，用正式产线做一小批，验证能不能稳定造出来
- OEM：你出设计，工厂按图纸生产，贴上你的牌子
- ODM：工厂有现成设计，你挑一款改改外观和软件，贴上你的牌子
- BRD：商业需求文档，回答为什么做（给老板看）
- MRD：市场需求文档，回答做给谁（给市场团队看）
- PRD：产品需求文档，回答做什么、做到什么标准（给研发看）
- 3C：中国强制安全认证，没有它很多产品不能在国内卖
- CE：欧洲安全认证，没有它很难在欧洲卖
- FCC：美国无线设备认证，没有它不能在美国卖
- IP65：防尘 + 防喷水，能扛住下雨淋
- IP68：防尘 + 能泡在水里，比 IP65 更高级
- 良率：100 台产品里合格的有多少台，比如良率 95% 就是 100 台里 95 台合格

### 第 3 题：硬件 PM 和软件 PM 有什么区别

#### 参考回答（三个区别）

> 第一是改错成本：软件出 bug 发个版本就修了，硬件出 bug 可能整批召回。第二是流程严谨度：软件可以敏捷开发、先上线再迭代，硬件必须走完 EVT、DVT、PVT 和认证这些阶段门。第三是商业风险：软件没库存压力，硬件要备料、压库存、铺渠道，卖不动全是钱。

#### 金句

软件是上线之后才真正开始，硬件是上市之前就必须全部想对。

### 10 条金句

1. B 端 = 卖给公司；硬件 = 改错贵；产品经理 = 定义对的产品并让它赚钱

8. BRD 回答为什么做，MRD 回答做给谁，PRD 回答做什么、做多好
9. 软件错误可以修，硬件错误只能扛
10. 产品经理不当传话筒，要当翻译官，中间永远垫着数据和方案

### 第 1 课：认证到底怎么考

- 认证不是一次考试，是好几层
- EMV Level 1：考卡和机器能不能正确对话（通信层）
- EMV Level 2：考交易逻辑对不对（扣钱、异常处理）
- PCI PTS：考机器安不安全（防改装、防卡信息泄露）
- 中国还有 PBOC / BCTC、SRRC、3C
- 认证要几个月，费用几万到几十万，改一次重测一次
- 产品经理必须在项目早期就把认证排进计划
- 比喻：Level 1 是科目二（车能开），Level 2 是科目三（上路规则），PCI 是安全驾驶检查

### 一句话记住

认证不是考一次，是考好几层，越早排进计划越省钱。

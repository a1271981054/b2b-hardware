# 硬件小岛

打开 `index.html`，或在本目录启动本地 HTTP 预览。HTML、样式、脚本与素材需要放在一起。

## 学习方式

- **课程地图**：60 个主题，按 8 个阶段组织，全部开放。
- **学习路线**：以冷链网关为贯穿项目，明确每阶段的输入、目标和产出。
- **项目练习**：逐步形成系统图、机会证据包、商业决策书、需求基线、开发计划、质量放行包、经营计划与完整方案。
- **我的足迹**：收藏、主题笔记、待复习问题和自测记录。

知识书架与听与看已从学习界面移除；原始项目文件未删除。分享包不再携带音视频。

## 课程内容

60 个主题，203 节课程。每个主题有一节完整主课，按关键判断、分步讲解、具体做法、完整案例、交付检查与延伸讨论组织。主课约 900–1500 字；加上原文展开，课程正文约 17.7 万字符。

课程使用 120 张独立生成的插画，每个主题各有概念图与场景图，相关原文章节复用本主题的配图；203 节每节呈现两张，共 406 处。插画通过原生 imagegen 按 image2 要求生成，提示词和来源清单保存在 artwork/。不再使用自动抽取表格生成的关系图。

图片可放大，图后可按步骤查看解释；课内目录可直接定位正文，手机的章节目录默认折叠。保留苹果系统字体、减少动态效果设置和键盘操作。图片用于教学，不是工程尺寸图、实测结果或统一验收标准。PNG 原图保留在本地，网站和分享包使用 WebP，压缩仅改变编码，不重新绘制。

新增 16 个主题：系统架构、试点、总拥有成本、路线图、接口、通信分层、供电与热、设备安全、固件升级、可制造与可测试性、供应商与关键物料、可靠性、FMEA、SPC、库存现金周期、经营指标。原有 44 个主题也补充了做法、产出和练习。

每个主题有两道场景/自测题，共 120 道；两题都答对只代表主题自测通过，不等于已完成全部章节或项目。术语共 62 个，可搜索，也可在“资料与使用说明”中打开。

## 来源与边界

原有 5 份核心资料完整编入课程；原稿中的历史数据、假设、历史作答和待答问题保留原有状态。新增课程在对应章节的“本节来源与阅读口径”列出相关一手资料。步骤、教学图和案例为课程编写，并不意味着参考机构提供了相同案例或推荐所有具体做法。

涉及 NASA 系统工程、NIST IoT 安全/统计/供应商选择、ASQ FMEA 与 8D、TI 通信分层、NXP 可测试性和 SBA 商业分析资料。检索及整理日期为 2026-10-20。公司、市场和财务历史资料没有当作最新数据重新发布。

可阅读的主课讲义见 `课程补充讲义.md`，其内容由构建脚本从课程源文件导出，来源索引见 `research/来源与使用范围.md`。

## 保存与兼容

章节位置、笔记、收藏、项目练习和自测保存在当前浏览器，可在设置中导入/导出 JSON。旧版收藏、笔记和自测继续保留；因目录扩充，阅读位置会作边界校验。不要清理浏览器数据而未备份。

字体为苹果系统字体栈：英文优先系统 SF，中文优先苹方；非苹果设备使用可用系统字体。动画遵循减少动态效果偏好，也可在设置中关闭。答题音效默认关闭。

本地预览：

```sh
python3 -m http.server 18876 --bind 127.0.0.1
```

访问 `http://127.0.0.1:18876/`。运行不需要联网；外部参考链接需要网络。

## 维护与核验

以下维护命令用于本地完整项目。分享 ZIP 只包含运行文件、课程讲义、来源资料和插画提示词，不包含构建脚本、检查记录与 PNG 原图。

在项目根目录运行 `python3 learning/build.py` 重建课程数据。维护文件为 `course.py`、`curriculum.py`、`deep_lessons.py`、`details.py`、`diagrams.py`，界面由 `app.js`、`journey.js`、`diagrams.js`、`style.css` 与 `reading.css` 实现。

静态核验：`python3 learning/qa/validate.py`。原文保真、内容覆盖、主课结构、每章插画数量、120 个不同图像文件、题目与资源引用均有检查。使用 `python3 learning/package.py` 重建分享 ZIP。

上一版的浏览器记录保存在 `qa/system-browser-report.json`，不代表本次改版的验收。本次的静态、图片与浏览器检查分别保存在 `qa/static-report.json`、`qa/art-review.json` 与 `qa/image2-browser-report.json`。手机检查使用 390×844 视口模拟。

内置浏览器不允许自动打开 `file://`，直接双击模式未在同一浏览器中实测；结构使用本地经典脚本与相对资源，不依赖网络请求或 CDN。


## 大白话阅读版

60 个主题的主讲解按零基础读者重新编写：先说具体发生了什么，再说明为什么要管、怎样做。183 段主要讲解、60 份操作方法和 180 条完成检查均逐课编写，继续保留案例、计算过程和两张课程插画。

专业词第一次出现时优先在上下文解释；正文、表格、练习说明和图后说明中的带点线文字可以点击，查看 103 条大白话解释。关闭后留在原来的阅读位置。词典、学习路线、阶段练习和互动控件也同步调整用语。

143 节原文展开在阅读时简化部分表达、补充术语解释。原始章节文本、源文件、表格数值和代码示例仍保留，方便核对；这部分没有被当作 143 篇全新改写的文章。入口仍在每节下方的“查看来源和原始资料”。

文字维护位置：`plain_language.py`；通过 `build.py` 生成网站和课程讲义。新增回归核验 `python3 learning/qa/plain_language.py` 对照改写前备份，检查章节身份、答题选项位置、原文、表格数字、代码和图片没有意外变化。此命令供完整项目使用，便携 ZIP 不包含构建与 QA 脚本。
